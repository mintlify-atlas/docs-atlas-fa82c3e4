Syft is an open source tool from [Anchore](https://anchore.com) that generates a Software Bill of Materials (SBOM) — a comprehensive inventory of all software components, packages, and dependencies in your container images and filesystems. Syft supports all major SBOM standards and integrates seamlessly with vulnerability scanners like Grype.

## What is an SBOM?

A Software Bill of Materials (SBOM) is a formal, machine-readable inventory of software components and dependencies. SBOMs enable:

- **Vulnerability management** — identify which components are affected by known CVEs
- **License compliance** — audit the open source licenses in your software supply chain
- **Supply chain security** — verify what is actually shipped in your container images

## Quick example

```bash
# Scan a container image and output CycloneDX JSON
syft alpine:latest -o cyclonedx-json

# Scan a local directory
syft ./my-project -o spdx-json

# Scan and save to a file
syft ubuntu:22.04 -o spdx-json=./sbom.json
```
