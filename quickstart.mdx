title: "Quickstart"
description: "Generate your first SBOM with Syft in under five minutes."
---

This guide walks you through scanning a container image, scanning a local directory, choosing an output format, and saving an SBOM to a file.

<Info>
  Make sure Syft is installed before you start. See the [Installation](/installation) page if you haven't installed it yet.
</Info>

<Steps>
  <Step title="Scan a container image">
    Pass any image reference to `syft`. Syft pulls the image from the registry (or from your local Docker daemon if it is already present) and prints a package summary to stdout:

    ```bash
    syft alpine:latest
    ```

    Example output:

    ```
    ✔ Loaded image                                                    alpine:latest
    ✔ Parsed image                                                    sha256:beefdbd8a1da6d2915566fde36db9db0b524eb737fc57cd1367effd16dc0d06d
    ✔ Cataloged packages              [14 packages]

    NAME                    VERSION      TYPE
    alpine-baselayout       3.4.3-r2     apk
    alpine-keys             2.4-r1       apk
    apk-tools               2.14.0-r5    apk
    busybox                 1.36.1-r5    apk
    ...
    ```

    <Tip>
      You can also use explicit source schemes. For example, `syft registry:alpine:latest` pulls directly from the registry without requiring a local Docker daemon.
    </Tip>
  </Step>

  <Step title="Scan a local directory">
    Point Syft at any directory on disk to catalogue the packages inside it:

    ```bash
    syft ./my-project
    ```

    Syft detects the project type automatically and catalogues packages from package manager manifests (e.g. `go.mod`, `package.json`, `requirements.txt`, `pom.xml`) and installed package databases it finds under the path.
  </Step>

  <Step title="Choose an output format">
    Use the `-o` flag to select a format. The default output is a human-readable table. For machine-readable SBOMs, choose one of the standard formats:

    <Tabs>
      <Tab title="CycloneDX JSON">
        ```bash
        syft alpine:latest -o cyclonedx-json
        ```
      </Tab>
      <Tab title="CycloneDX XML">
        ```bash
        syft alpine:latest -o cyclonedx
        ```
      </Tab>
      <Tab title="SPDX JSON">
        ```bash
        syft alpine:latest -o spdx-json
        ```
      </Tab>
      <Tab title="SPDX Tag-Value">
        ```bash
        syft alpine:latest -o spdx
        ```
      </Tab>
      <Tab title="Syft JSON">
        ```bash
        syft alpine:latest -o json
        ```
      </Tab>
    </Tabs>

    To request a specific version of a format, append `@<version>`:

    ```bash
    # SPDX 2.2 instead of the default 2.3
    syft alpine:latest -o spdx-json@2.2

    # CycloneDX 1.4
    syft alpine:latest -o cyclonedx-json@1.4
    ```
  </Step>

  <Step title="Save the SBOM to a file">
    Append `=<path>` to the format value to write the output to a file instead of stdout:

    ```bash
    # Write SPDX JSON to a file
    syft alpine:latest -o spdx-json=./sbom.json
    ```

    You can write multiple formats in a single scan by repeating the `-o` flag:

    ```bash
    # Write both SPDX JSON and CycloneDX JSON in one run
    syft alpine:latest -o spdx-json=./sbom.spdx.json -o cyclonedx-json=./sbom.cdx.json
    ```
  </Step>

  <Step title="Scan with verbose output">
    Add `-vv` to see detailed debug information about what Syft is doing, including which catalogers are active and what files they are examining:

    ```bash
    syft alpine:latest -vv
    ```
  </Step>
</Steps>

## Common scan targets

<CodeGroup>

```bash Container image (Docker / OCI)
syft alpine:latest
syft ubuntu:22.04
syft my-org/my-app:v1.2.3
```

```bash Local directory
syft ./my-project
syft dir:./my-project
```

```bash Explicit source schemes
# Pull directly from registry (no Docker daemon needed)
syft registry:alpine:latest

# Scan a Docker archive
syft docker-archive:./my-image.tar

# Scan an OCI archive (e.g. from Skopeo)
syft oci-archive:./my-image.tar

# Scan a Singularity image
syft singularity:./my-image.sif
```

```bash Save to file
syft alpine:latest -o cyclonedx-json=./sbom.json
syft ./my-project -o spdx-json=./sbom.spdx.json
```

</CodeGroup>
