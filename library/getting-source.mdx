---
title: "Getting a source"
description: "Resolve any container image, directory, or archive into a Syft source object."
---

Before cataloging can begin, Syft needs a `source.Source` — an abstraction that decouples *what* is being scanned from *how* it is scanned. `syft.GetSource` resolves an arbitrary input string into this object.

## Function signature

```go
func GetSource(ctx context.Context, userInput string, cfg *GetSourceConfig) (source.Source, error)
```

Syft tries each of its registered source providers in order until one succeeds. If no provider can resolve the input, a descriptive error is returned.

<Tip>
  Pass `nil` for `cfg` to use `DefaultGetSourceConfig()`, which is the right choice for most applications.
</Tip>

## Input formats

`GetSource` accepts the same input strings as the CLI:

| Input | Example |
|---|---|
| Docker image reference | `alpine:3.19` |
| OCI image path | `oci:/path/to/image` |
| OCI directory | `oci-dir:/path/to/dir` |
| Docker daemon image | `docker:alpine:latest` |
| Local directory | `/path/to/dir` or `dir:/path/to/dir` |
| Local archive | `/path/to/image.tar` |
| Podman image | `podman:myimage` |

## GetSourceConfig

`GetSourceConfig` controls how source providers are constructed and ordered.

```go
type GetSourceConfig struct {
    // SourceProviderConfig may optionally be provided to be used when constructing
    // the default set of source providers, unused if Sources is specified.
    SourceProviderConfig *sourceproviders.Config

    // Sources is an explicit list of source names to use, in order, to attempt
    // to locate a source.
    Sources []string

    // DefaultImagePullSource will cause a particular image pull source to be used
    // as the first pull source, followed by other pull sources.
    DefaultImagePullSource string
}
```

### Builder methods

All methods return `*GetSourceConfig` for chaining:

| Method | Description |
|---|---|
| `WithAlias(alias source.Alias)` | Attach a display alias to the source |
| `WithRegistryOptions(opts *image.RegistryOptions)` | Configure registry auth, TLS, and mirrors |
| `WithPlatform(platform *image.Platform)` | Pin a specific OS/architecture for multi-platform images |
| `WithExcludeConfig(cfg source.ExcludeConfig)` | Specify glob patterns to exclude paths |
| `WithDigestAlgorithms(algorithms ...crypto.Hash)` | Set the hash algorithms used for source digests |
| `WithBasePath(basePath string)` | Override the base path used for relative file references |
| `WithSources(sources ...string)` | Restrict which source providers are tried, in order |
| `WithDefaultImagePullSource(s string)` | Promote a named pull source to be tried first |

### DefaultGetSourceConfig

```go
func DefaultGetSourceConfig() *GetSourceConfig
```

Returns a `*GetSourceConfig` pre-populated with sensible defaults, including `sourceproviders.DefaultConfig()`.

## Examples

<Tabs>
  <Tab title="Default (nil config)">
    ```go
    src, err := syft.GetSource(context.Background(), "alpine:3.19", nil)
    if err != nil {
        return err
    }
    defer src.Close()
    ```
  </Tab>
  <Tab title="Specific platform">
    ```go
    cfg := syft.DefaultGetSourceConfig().
        WithPlatform(&image.Platform{
            OS:           "linux",
            Architecture: "arm64",
        })

    src, err := syft.GetSource(context.Background(), "alpine:3.19", cfg)
    if err != nil {
        return err
    }
    defer src.Close()
    ```
  </Tab>
  <Tab title="Exclude paths">
    ```go
    cfg := syft.DefaultGetSourceConfig().
        WithExcludeConfig(source.ExcludeConfig{
            Paths: []string{"/proc", "/sys"},
        })

    src, err := syft.GetSource(context.Background(), "/", cfg)
    if err != nil {
        return err
    }
    defer src.Close()
    ```
  </Tab>
  <Tab title="Registry with auth">
    ```go
    cfg := syft.DefaultGetSourceConfig().
        WithRegistryOptions(&image.RegistryOptions{
            Credentials: []image.RegistryCredentials{
                {
                    Authority: "registry.example.com",
                    Username:  "user",
                    Password:  "pass",
                },
            },
        })

    src, err := syft.GetSource(context.Background(), "registry.example.com/myapp:latest", cfg)
    if err != nil {
        return err
    }
    defer src.Close()
    ```
  </Tab>
</Tabs>

## Closing the source

`source.Source` implements `io.Closer`. Always call `Close()` when finished to release any resources (temporary directories, open file handles, etc.):

```go
src, err := syft.GetSource(ctx, input, nil)
if err != nil {
    return err
}
defer src.Close()
```

## Error handling

`GetSource` returns a non-nil error when:

- No provider could resolve the input string
- A provider encountered an error other than file-not-found
- The resolved source type does not support the requested `Platform` (only image sources support platform pinning)

When multiple providers fail, the error message aggregates all individual failures for easier debugging.
